# Технические заметки

## Структура проекта

| Каталог | Назначение |
| --- | --- |
| `app/` | Общий интерфейс, импорт подписок и генерация конфигурации Xray. |
| `android/` | Android-клиент и служба системного VPN. |
| `desktop/` | Клиент Electron, запуск Xray и управление туннелем Windows. |
| `website/`, `deploy/` | Страница загрузки и конфигурация её хостинга. |
| `scripts/`, `test/` | Сборка, манифест обновлений и тесты. |

## Подписки и измерения

Ссылки подписок хранятся на устройстве. ShareSub использует постоянный X-HWID установки. Для сторонних HTTPS-провайдеров клиент формирует отдельный постоянный HWID для каждого исходного HTTPS-origin. Импорт по диплинку требует подтверждения.

Пинг измеряет время установления TCP-соединения с портом сервера. Для UDP-серверов Hysteria2 это измерение может быть недоступно. Балансер измеряет задержку через сам туннель.

Показатель ОЗУ отражает используемую Go-кучу Xray на Android и резидентную память процесса `xray.exe` на Windows. Разряд — оценка общего расхода батареи устройства во время VPN-сеанса. Для Android нужны показания счётчика заряда как минимум за пять минут. Windows использует данные WMI при наличии поддерживаемого датчика.

## Публикация обновлений

1. Соберите установщики для Windows и Android. Подпишите Android APK тем же ключом, который использовался для предыдущих релизов.
2. Создайте манифест командой ниже. Требуются Python 3.11+ и пакет `cryptography`.
3. Загрузите установщики в каталог релизов хоста. Затем обновите ссылки `latest.apk` и `latest.exe` и опубликуйте новый `latest.json`.

```text
python scripts/release-feed.py --key <путь-к-ключу> --version <версия> --android-code <код-сборки> --output dist/latest.json
```

Клиенты проверяют подпись блока `payload` с помощью открытого ключа из `app/update-public.pem`, а затем сверяют размер и SHA‑256 установщика. Приватные ключи подписи APK и манифеста хранятся вне репозитория и веб-сервера.
